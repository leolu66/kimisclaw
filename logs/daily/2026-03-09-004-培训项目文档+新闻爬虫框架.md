**核心设计决策**：

### 任务3：实现新闻爬虫代码框架

**描述**：从零实现完整的可配置新闻采集框架。

**实现模块**：
1. **config_loader.py** (210行)：配置加载器，支持热更新、配置验证、版本迁移
2. **extractors.py** (395行)：字段提取器，支持 4 种选择器类型 + 7 种数据转换器
3. **engine.py** (493行)：异步采集引擎，支持请求频率控制、重试机制、并发控制
4. **storage.py** (193行)：存储模块，支持 JSON/JSONL/CSV/Markdown 格式
5. **monitor.py** (178行)：监控告警，跟踪站点健康状态和提取成功率
6. **spider_cli.py** (343行)：命令行工具，支持配置测试、网页探测、单站点采集
7. **main.py** (151行)：主入口，支持批量采集、多格式输出

**站点配置示例**：
- `_template.yaml`：详细注释的配置模板
- `jiqizhixin.yaml`：机器之心站点配置
- `qbitai.yaml`：量子位站点配置

**命令行工具功能**：
```bash
python3 spider_cli.py list-sites    # 列出所有站点
python3 spider_cli.py test SITE     # 测试配置
python3 spider_cli.py probe URL     # 探测网页结构
python3 spider_cli.py crawl SITE    # 运行采集
python3 main.py                     # 批量采集所有站点
```

**测试验证**：
- 依赖安装：`pip3 install lxml aiohttp pyyaml click python-dateutil cssselect`
- 配置加载测试通过：成功识别 2 个站点配置

## 关键决策与成果

- **架构设计**：采用"配置驱动 + 适配器模式"，新增站点只需复制模板、填写选择器、测试验证三步
- **技术选型**：使用 `aiohttp` 实现异步采集，`lxml` 支持 XPath/CSS，`PyYAML` 管理配置
- **可维护性**：配置与代码分离，网站改版时升级 `config_version` 并更新选择器即可
- **交付成果**：完整的 `news-spider/` 项目，包含 7 个核心模块 + 3 个示例配置 + CLI 工具
