# 《培训管理系统》需求设计文档

## 1. 需求概述

**目标用户：**
- 系统管理员（运营人员）
- 培训老师（只读展示）
- 培训学员（注册+评价）

**核心场景：**
管理员安排培训 → 生成注册二维码 → 老师嵌入PPT → 学员扫码注册 → 培训后填写反馈

**技术约束：**
- 微信小程序原生开发
- 微信云开发（云数据库+云函数）
- 无需短信验证码（微信登录优先）

## 3. 页面结构

```
【管理员端】
├── 首页（数据看板：待办任务数、本月培训数）
├── 课程管理
│   └── 列表 → 新增/编辑/删除
├── 老师管理
│   └── 列表 → 新增/编辑/删除
├── 单位管理
│   └── 列表 → 新增/编辑/删除
├── 培训任务
│   ├── 任务列表（筛选+分页）
│   ├── 创建任务（表单）
│   ├── 任务详情
│   │   ├── 基本信息
│   │   ├── 二维码（展示+保存）
│   │   ├── 学员名单
│   │   └── 调查结果
│   └── 编辑任务
└── 调查模板
    ├── 模板列表
    ├── 创建模板（题目编辑器）
    └── 绑定任务

【老师端】
└── 我的培训（只显示分配给该老师的任务）
    └── 任务详情 → 展示二维码（全屏，方便投影）

【学员端】
├── 扫码入口（二维码扫描）
├── 注册页面（微信登录+填写信息）
├── 登录页面（微信一键登录/手机号登录）
├── 培训列表（我参加的培训）
└── 填写调查表（培训结束后显示）
```

## 4. 数据模型

### 课程 courses
```yaml
- _id: string
- name: string        # 课程名称
- description: string # 课程简介
- duration: number    # 时长（分钟）
- createdAt: date
```

### 老师 teachers
```yaml
- _id: string
- name: string
- title: string       # 职称/头衔
- avatar: string      # 头像URL
- bio: string         # 简介
- createdAt: date
```

### 单位 units
```yaml
- _id: string
- name: string        # 单位名称（如"中国石油北京分公司"）
- createdAt: date
```

### 培训任务 tasks
```yaml
- _id: string
- title: string       # 培训标题
- courseId: ref       # 关联课程
- teacherId: ref      # 关联老师
- unitId: ref         # 关联单位
- date: date          # 培训日期
- location: string    # 培训地点
- capacity: number    # 计划人数（仅作参考，不限制报名）
- status: enum        # planned/ongoing/completed/cancelled
- surveyTemplateId: ref # 关联的调查模板
- qrCodeUrl: string   # 二维码图片URL
- createdAt: date
```

### 调查模板 survey_templates
```yaml
- _id: string
- name: string        # 模板名称
- questions: array    # 题目列表
  # - type: radio/checkbox/text
  # - title: string
  # - options: array (for radio/checkbox)
- createdAt: date
```

### 学员 users
```yaml
- _id: string
- openid: string      # 微信openid
- name: string        # 姓名
- phone: string       # 手机号
- email: string       # 邮箱
- wechatId: string    # 微信号
- password: string    # 密码（加密存储）
- unitId: ref         # 所属单位（从培训任务带入）
- createdAt: date
```

### 培训报名 registrations
```yaml
- _id: string
- taskId: ref         # 培训任务
- userId: ref         # 学员
- registeredAt: date  # 报名时间
- status: enum        # registered/cancelled/completed
```

### 调查结果 survey_responses
```yaml
- _id: string
- taskId: ref
- userId: ref
- templateId: ref
- answers: array      # 答案列表
- submittedAt: date
```

## 5. 关键流程

### 二维码生成逻辑
1. 创建培训任务后，生成二维码
2. 二维码内容：`pages/register/register?taskId=xxx&unitId=xxx`
3. 使用微信二维码接口生成图片，保存到云存储

### 学员注册流程
1. 扫码进入注册页，URL参数包含taskId和unitId
2. 微信授权登录，获取openid、昵称、头像
3. 展示表单：姓名、手机、邮箱、微信号、密码、确认密码
4. 单位字段自动填入（从URL参数，不可修改）
5. 提交后：创建user记录 + 创建registration记录

### 培训评价流程
1. 培训结束后，管理员修改任务状态为completed
2. 学员进入"我的培训"，显示可评价的培训
3. 点击进入调查表页面，动态渲染题目
4. 提交后保存survey_responses

## 6. 边界情况

- **重复扫码**：
  - 已注册用户：自动登录，进入培训详情或评价页面
  - 未注册用户：显示注册表单
- **培训取消**：任务取消后，二维码失效，提示"该培训已取消"
- **微信未授权**：拒绝授权时，引导手动填写信息
