# 培训管理系统微信小程序 - 部署指南

## 前置条件

1. 已注册微信小程序账号（企业/个人均可）
2. 已开通微信云开发
3. 安装微信开发者工具（最新稳定版）

---

## 1. 克隆仓库

```bash
git clone https://github.com/leolu66/SongTrainingProj.git
cd SongTrainingProj
```

---

## 2. 导入项目

1. 打开 **微信开发者工具**
2. 点击 **导入项目**
3. 选择 `SongTrainingProj` 文件夹
4. 填写你的小程序 AppID
5. 勾选 **使用云服务** → 选择 **云开发环境**
6. 点击 **确定**

---

## 3. 配置云开发环境

### 3.1 修改环境 ID

打开 `miniprogram/app.js`，找到第 5 行：

```javascript
env: 'your-env-id', // 替换为你的云开发环境 ID
```

替换为你的实际环境 ID（在微信开发者工具 → 云开发 → 设置 中查看）。

### 3.2 开通云开发服务

1. 微信开发者工具 → 点击 **云开发** 按钮
2. 按提示开通（选择免费套餐即可）
3. 记录 **环境 ID**

---

## 4. 部署云函数

### 4.1 创建云函数目录

在微信开发者工具中：
1. 右键 `cloudfunctions/` 文件夹
2. 选择 **新建云函数**
3. 依次创建以下 8 个云函数：
   - `initDb` - 初始化数据库集合
   - `login` - 微信登录
   - `registerUser` - 用户注册
   - `getTasks` - 获取培训任务列表
   - `getTaskDetail` - 获取任务详情
   - `generateQRCode` - 生成二维码
   - `submitSurvey` - 提交调查表
   - `getSurveyStats` - 获取调查统计

### 4.2 上传云函数

对于每个云函数：
1. 右键点击云函数文件夹（如 `cloudfunctions/login`）
2. 选择 **创建并部署：云端安装依赖**
3. 等待部署完成（控制台显示上传成功）

**或者批量部署命令（在终端中）：**
```bash
# 需要先安装微信 CLI 工具
wxcloud login

# 部署所有云函数
for func in initDb login registerUser getTasks getTaskDetail generateQRCode submitSurvey getSurveyStats; do
  wxcloud functions deploy --name $func --path cloudfunctions/$func
done
```

## 5. 初始化数据库

### 5.1 创建数据库集合

**方式一：使用 initDb 云函数（推荐）**

1. 在微信开发者工具中，打开 **云开发** → **云函数**
2. 找到 `initDb`，点击 **调试**
3. 点击 **运行**，等待初始化完成

**方式二：手动创建**

1. 微信开发者工具 → **云开发** → **数据库**
2. 点击 **添加集合**，依次创建：
   - `courses` - 课程
   - `teachers` - 老师
   - `units` - 单位
   - `tasks` - 培训任务
   - `survey_templates` - 调查模板
   - `users` - 学员
   - `registrations` - 报名记录
   - `survey_responses` - 调查结果

### 5.2 设置数据库权限

对于每个集合，设置权限为 **所有用户可读，仅创建者可写**：

1. 进入集合 → **权限设置**
2. 选择 **自定义权限**
3. 粘贴以下规则：

```json
{
  "read": true,
  "write": "doc._openid == auth.openid || true"
}
```

**注意：** 生产环境建议调整为更严格的权限规则。

## 6. 配置小程序

### 6.1 配置页面路径

确保 `app.json` 中的 `pages` 已包含所有页面（已配置好，一般无需修改）。

### 6.2 配置网络请求域名

如果使用了外部接口，需要在小程序后台配置 request 合法域名。

### 6.3 配置二维码规则（可选）

如需生成小程序码，需在小程序后台 → 开发 → 开发设置 → 扫普通链接二维码打开小程序 中配置规则。

## 9. 发布上线

### 9.1 提交审核

1. 微信开发者工具 → 点击 **上传**
2. 填写版本号（如 1.0.0）和项目备注
3. 登录小程序后台 → **管理** → **版本管理**

审核通过后，在小程序后台点击 **发布**。

## 10. 常见问题

### Q1: 云函数调用失败，提示 "errMsg": "cloud.callFunction:fail"

**解决：**
- 确认云函数已部署（右键 → 创建并部署）
- 确认 `app.js` 中的环境 ID 正确
- 查看云函数日志（云开发 → 云函数 → 日志）

### Q2: 数据库查询返回空数组

**解决：**
- 确认集合已创建
- 确认数据库权限已设置为可读
- 确认查询条件正确

### Q3: 二维码生成失败

**解决：**
- 确认已部署 `generateQRCode` 云函数
- 确认小程序已发布或使用了预览版/体验版 appid
- 检查云函数日志中的具体错误

### Q4: 微信登录获取不到用户信息

**解决：**
- 确认已部署 `login` 云函数
- 确认小程序后台 → 开发 → 开发设置 中已配置服务器域名
- 检查 `wx.login` 和 `wx.getUserProfile` 的调用方式

### Q5: 页面白屏或样式错乱

**解决：**
- 检查控制台报错信息
- 确认基础库版本（建议 2.19.4 以上）
- 清理缓存（开发者工具 → 详情 → 本地缓存 → 清除缓存）
